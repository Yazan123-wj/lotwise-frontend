# Image slots

Catalogue, category, and banner photographs are temporary editorial images used so the storefront can be reviewed with real photography. They are not LotWise Labs product shots and do not describe a specific compound.

Replace these files with official photography when it is supplied. Keep the same filenames, or update the paths in `src/data/products.ts`, `src/data/categories.ts`, and `src/data/banners.ts`.

The official logo still belongs in `brand/` when it is available.
